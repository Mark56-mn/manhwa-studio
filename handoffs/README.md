# Handoffs

One handoff file per completed task, written **before** the next task starts.
Each handoff records: what changed; commands actually run and their real
results; what passed, failed, was blocked, or was not tested; whether a live
deployment was exercised and how; decisions taken; and the exact next task file
with what the next agent must do.
